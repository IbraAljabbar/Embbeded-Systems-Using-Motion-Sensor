# Embedded Systems Smart Home Security System

Welcome to the Embedded Systems Smart Home Security System repository. This project is a standalone home security and automated lighting prototype powered by the ESP8266 development board. It is designed to safeguard residential spaces by detecting unauthorized movement and monitoring ambient light levels to manage energy consumption.

By combining motion sensing with light-level awareness, this system serves as an integrated intrusion alert mechanism and automatic night-light solution for modern smart home infrastructures.

### Core Features
- Intrudor Detection: Utilizes a Passive Infrared (PIR) motion sensor to scan the surroundings for human movement and trigger instant safety responses.
- Ambient Light Awareness: Employs a Light Dependent Resistor (LDR) to track shifting brightness levels, allowing the system to distinguish between day and night conditions.
- Automated Lighting: Changes the state of a localized LED based on real-time lighting levels, acting as an automatic night lamp.
- Local Audible Alarm: Triggers a high-output Piezo Buzzer to broadcast an immediate sound warning the moment unauthorized movement is captured in a secure zone.
- High Prototyping Scalability: Built on the ESP8266 development framework, making it highly adaptable for future expansion into networked smart home environments.
